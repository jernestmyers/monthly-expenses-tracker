# Frontend

This project uses [Vite](https://vite.dev/) for development and bundling, [Vitest](https://vitest.dev/) for tests, and TypeScript + React.

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode with hot module reloading.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### `npm test`

Runs the test suite once via Vitest.

### `npm run build`

Builds the app for production to the `build` folder (bundled, minified, content-hashed filenames). The backend serves this folder as static assets in production.

### `npm run preview`

Serves the production build locally for a final sanity check.
